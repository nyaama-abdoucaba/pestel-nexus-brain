# Décisions d'architecture (ADR)

Un fichier par choix technique difficile à défaire.

Nommage : `AAAA-MM-JJ-<decision-a-l-affirmatif>.md`.

Un ADR ne se modifie jamais. Quand la décision change, un nouvel ADR remplace
l'ancien, et l'ancien passe en statut remplacé.

La section qui porte la valeur est celle des conséquences acceptées : ce que le
choix rend difficile, assumé par écrit.

Contenu attendu : voir `docs/PROCESS.md`, section 6.
