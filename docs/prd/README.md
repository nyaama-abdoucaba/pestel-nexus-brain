# PRD

Un PRD par chantier majeur. Il porte le pourquoi et le quoi, en langage métier.
Il ne nomme aucune bibliothèque et ne montre aucun schéma de table.

Nommage : `AAAA-MM-JJ-<sujet>-prd.md`.

Un PRD survit à ses slices. Il se relit deux ans plus tard, c'est pourquoi il vit
dans `docs/` et non dans `tasks/`.

Contenu attendu et règles de version : voir `docs/PROCESS.md`, section 3.
