# Spikes

Un spike est une exploration bornée dans le temps, qui répond à une question dont
dépend l'architecture. Son code est jetable par construction.

Nommage : `AAAA-MM-JJ-<question-en-trois-mots>.md`.

La durée maximale se décide avant de commencer. Un spike qui dépasse son temps
est un spike raté, et un spike raté dit que la question est plus profonde qu'on
ne le croyait.

Contenu attendu : voir `docs/PROCESS.md`, section 7.
