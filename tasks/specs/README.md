# Specs techniques

Une spec dit comment. Elle traduit une exigence du PRD en décisions techniques,
et se relit avant l'implémentation.

Nommage : `AAAA-MM-JJ-<sujet>-spec.md`.

Une spec ne justifie aucun seuil métier. Si elle doit défendre une règle de tri,
la décision a sauté une étape et il faut remonter au PRD.

Contenu attendu : voir `docs/PROCESS.md`, section 5.
